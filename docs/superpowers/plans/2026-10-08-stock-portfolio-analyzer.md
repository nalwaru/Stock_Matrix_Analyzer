# Stock Portfolio Analyzer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Streamlit stock portfolio analyzer that ingests a CSV, enriches it with live `yfinance` prices, shows KPIs/charts/filters, a what-if stress simulator, OpenAI-powered audit and chat, and CSV export.

**Architecture:** `app.py` is UI wiring only. Financial logic lives in pure, unit-tested modules (`schema`, `portfolio`, `scenarios`, `export`); thin adapters wrap `yfinance` (`market`) and OpenAI (`ai`), and the Streamlit caching decorators sit on those adapters.

**Tech Stack:** Python, `uv`, Streamlit, pandas, Plotly Express, yfinance, openai, python-dotenv, pytest.

**Spec:** `docs/superpowers/specs/2026-10-08-stock-portfolio-analyzer-design.md`

## Global Constraints

- Required CSV columns, exact names: `Ticker`, `Shares`, `Purchase_Price`, `Purchase_Date`, `Asset_Class`.
- Run command must work: `uv run streamlit run app.py`. Tests: `uv run pytest`.
- LLM provider is OpenAI (`openai` SDK); model from `OPENAI_MODEL` (default `gpt-4o-mini`); key from `OPENAI_API_KEY` (env or `.env`).
- `yfinance` quote fetch is cached with `@st.cache_data(ttl=300)`; the AI audit is `@st.cache_data` keyed by the summary payload.
- Only aggregated data (allocation %, top 3 positions, ROI, counts) is ever sent to OpenAI. Never raw rows.
- Percent columns/values (`*_Pct`, `*_pct`) are in **percent units** (12.5 means 12.5%). Scenario shocks passed to `apply_shocks` are **fractions** (-0.2 means -20%).
- Missing/failed prices are never silently zero: they are NaN with `Price_Status == "unavailable"`, or `"stale"` (purchase price) when the entire fetch failed.
- Secrets: `.env` is gitignored; `.env.example` is committed.
- Every commit message gets this trailer (second `-m`): `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`
- Deviations from the spec made by this plan (Task 1 updates the spec to match): package lives at top-level `analyzer/` (not `src/analyzer/`) so Streamlit's script-dir `sys.path` finds it with no path hacks; `python-dotenv` added as a dependency to load `.env`.

## Review Focus

1. A ticker with no quote (e.g. delisted symbol): excluded from totals, flagged, no crash. (Task 4)
2. Filters leave zero rows, or every price is unavailable: summary returns zeros, no ZeroDivisionError. (Task 4, Task 8)
3. A CSV with padding rows, extra empty/`Unnamed` columns, lowercase or whitespace-padded tickers (the user's real sample file looks like this). (Task 2)
4. Zero cost basis (`Purchase_Price` 0): percentages are NaN/0, not inf. (Task 4)
5. Missing `OPENAI_API_KEY` or an OpenAI API error: the AI feature degrades with a message; the rest of the app keeps working. (Task 7)

```python
"""CSV schema validation for portfolio uploads."""
from dataclasses import dataclass, field

import pandas as pd

REQUIRED_COLUMNS = ["Ticker", "Shares", "Purchase_Price", "Purchase_Date", "Asset_Class"]


@dataclass
class ValidationResult:
    df: pd.DataFrame
    errors: list[str] = field(default_factory=list)
    warnings: list[str] = field(default_factory=list)


def _csv_lines(index) -> str:
    # index is the original 0-based row index; +2 = header line + 1-based row.
    return ", ".join(str(int(i) + 2) for i in index)


def _clean_text(series: pd.Series) -> pd.Series:
    return series.where(series.notna(), "").astype(str).str.strip()


def validate(raw: pd.DataFrame) -> ValidationResult:
    df = raw.copy()
    df.columns = [str(c).strip() for c in df.columns]
    df = df.dropna(how="all")
    empty_extras = [
        c for c in df.columns if c not in REQUIRED_COLUMNS and df[c].isna().all()
    ]
    df = df.drop(columns=empty_extras)

    missing = [c for c in REQUIRED_COLUMNS if c not in df.columns]
    if missing:
        return ValidationResult(
            df.iloc[0:0],
            errors=[f"Missing required column(s): {', '.join(missing)}"],
        )

    df = df[REQUIRED_COLUMNS].copy()
    df["Ticker"] = _clean_text(df["Ticker"]).str.upper()
    df["Asset_Class"] = _clean_text(df["Asset_Class"])
    df["Shares"] = pd.to_numeric(df["Shares"], errors="coerce")
    df["Purchase_Price"] = pd.to_numeric(df["Purchase_Price"], errors="coerce")
    df["Purchase_Date"] = pd.to_datetime(df["Purchase_Date"], errors="coerce", format="mixed")

    checks = {
        "missing ticker": df["Ticker"] == "",
        "missing asset class": df["Asset_Class"] == "",
        "shares must be a positive number (zero, negative or non-numeric)": ~(df["Shares"] > 0),
        "purchase price must be a non-negative number": ~(df["Purchase_Price"] >= 0),
        "invalid purchase date": df["Purchase_Date"].isna(),
    }
    warnings: list[str] = []
    bad = pd.Series(False, index=df.index)
    for reason, mask in checks.items():
        if mask.any():
            label = "row" if mask.sum() == 1 else "rows"
            warnings.append(f"Dropped {label} {_csv_lines(df.index[mask])}: {reason}")
            bad |= mask

    df = df[~bad].reset_index(drop=True)
    errors = [] if len(df) else ["No valid holdings found in the file."]
    return ValidationResult(df, errors=errors, warnings=warnings)
```

```python
"""yfinance adapter. Returns quotes as a DataFrame; never invents values."""
import math

import pandas as pd
import streamlit as st
import yfinance

QUOTE_COLUMNS = ["Price", "Prev_Close", "Week52_High", "Week52_Low"]
_FAST_INFO_ATTRS = {
    "Price": "last_price",
    "Prev_Close": "previous_close",
    "Week52_High": "year_high",
    "Week52_Low": "year_low",
}


class MarketDataError(RuntimeError):
    """Raised when quotes cannot be retrieved at all."""


def empty_quotes() -> pd.DataFrame:
    return pd.DataFrame(
        columns=QUOTE_COLUMNS, index=pd.Index([], name="Ticker"), dtype=float
    )


def _read(info, attr: str) -> float:
    try:
        value = float(getattr(info, attr))
    except (AttributeError, KeyError, TypeError, ValueError):
        return math.nan
    return value if math.isfinite(value) and value > 0 else math.nan


def fetch_quotes_uncached(tickers: tuple[str, ...], yf_module=yfinance) -> pd.DataFrame:
    if not tickers:
        return empty_quotes()
    try:
        handle = yf_module.Tickers(" ".join(tickers))
    except Exception as exc:  # network/library failure
        raise MarketDataError(f"yfinance request failed: {exc}") from exc

    rows = {}
    for symbol in tickers:
        try:
            info = handle.tickers[symbol].fast_info
        except Exception:
            rows[symbol] = [math.nan] * len(QUOTE_COLUMNS)
            continue
        rows[symbol] = [_read(info, _FAST_INFO_ATTRS[c]) for c in QUOTE_COLUMNS]

    quotes = pd.DataFrame.from_dict(rows, orient="index", columns=QUOTE_COLUMNS)
    quotes.index.name = "Ticker"
    if quotes["Price"].isna().all():
        raise MarketDataError("No prices were returned for any ticker.")
    return quotes


@st.cache_data(ttl=300, show_spinner="Fetching market data...")
def fetch_quotes(tickers: tuple[str, ...]) -> pd.DataFrame:
    return fetch_quotes_uncached(tickers)
```

```python
        ("AAPL", 10, 100.0, "Stocks"),

        {
            "Ticker": [r[0] for r in rows],
            "Shares": [float(r[1]) for r in rows],
            "Purchase_Price": [r[2] for r in rows],
```

```python
"""Pure portfolio math: no Streamlit imports."""
import numpy as np
import pandas as pd

from analyzer.market import QUOTE_COLUMNS


def _pct(numerator: pd.Series, denominator: pd.Series) -> pd.Series:
    """Percent (x100); NaN where the denominator is not positive."""
    return numerator / denominator.where(denominator > 0) * 100


def _safe_pct(numerator: float, denominator: float) -> float:
    return float(numerator / denominator * 100) if denominator > 0 else 0.0


def enrich(
    holdings: pd.DataFrame, quotes: pd.DataFrame, fallback_to_cost: bool = False
) -> pd.DataFrame:
    df = holdings.merge(
        quotes.reindex(columns=QUOTE_COLUMNS),
        left_on="Ticker",
        right_index=True,
        how="left",
    )
    live = df["Price"].notna()
    df["Price_Status"] = np.where(live, "live", "stale" if fallback_to_cost else "unavailable")
    if fallback_to_cost:
        df["Price"] = df["Price"].fillna(df["Purchase_Price"])
        df["Prev_Close"] = df["Prev_Close"].fillna(df["Price"])

    df["Cost_Basis"] = df["Shares"] * df["Purchase_Price"]
    df["Current_Value"] = df["Shares"] * df["Price"]
    df["Gain_Loss"] = df["Current_Value"] - df["Cost_Basis"]
    df["Gain_Loss_Pct"] = _pct(df["Gain_Loss"], df["Cost_Basis"])
    previous_value = df["Shares"] * df["Prev_Close"]
    df["Day_Change"] = df["Current_Value"] - previous_value
    df["Day_Change_Pct"] = _pct(df["Day_Change"], previous_value)
    return df.reset_index(drop=True)


def summary(df: pd.DataFrame) -> dict:
    priced = df[df["Current_Value"].notna()]
    total_value = float(priced["Current_Value"].sum())
    total_cost = float(priced["Cost_Basis"].sum())
    total_gain = total_value - total_cost
    day_pnl = float(priced["Day_Change"].sum())
    return {
        "total_value": total_value,
        "total_cost": total_cost,
        "total_gain": total_gain,
        "total_gain_pct": _safe_pct(total_gain, total_cost),
        "day_pnl": day_pnl,
        "day_pnl_pct": _safe_pct(day_pnl, total_value - day_pnl),
        "positions": int(len(priced)),
        "unpriced": int(len(df) - len(priced)),
    }


def allocation(df: pd.DataFrame) -> pd.DataFrame:
    return (
        df.dropna(subset=["Current_Value"])
        .groupby("Asset_Class", as_index=False)["Current_Value"]
        .sum()
        .sort_values("Current_Value", ascending=False)
        .reset_index(drop=True)
    )


def top_holdings(df: pd.DataFrame, n: int = 10) -> pd.DataFrame:
    return (
        df.dropna(subset=["Current_Value"])
        .groupby("Ticker", as_index=False)["Current_Value"]
        .sum()
        .nlargest(n, "Current_Value")
        .reset_index(drop=True)
    )


def ai_summary(df: pd.DataFrame) -> dict:
    """Aggregated, rounded payload: the only portfolio data sent to the LLM."""
    s = summary(df)
    total = s["total_value"]
    alloc = allocation(df)
    top = top_holdings(df, 3)
    return {
        "total_value": round(total, 2),
        "total_roi_pct": round(s["total_gain_pct"], 2),
        "position_count": s["positions"],
        "allocation_pct": {
            cls: round(value / total * 100, 2)
            for cls, value in zip(alloc["Asset_Class"], alloc["Current_Value"])
        }
        if total > 0
        else {},
        "top_positions": [
            {
                "ticker": ticker,
                "value": round(value, 2),
                "weight_pct": round(value / total * 100, 2),
            }
            for ticker, value in zip(top["Ticker"], top["Current_Value"])
        ]
        if total > 0
        else [],
    }
```

```python
"""What-if stress testing: pure functions over the enriched frame."""
import pandas as pd


def apply_shocks(df: pd.DataFrame, shocks: dict[str, float]) -> pd.DataFrame:
    """Return a copy with Simulated_Value. Shocks are fractions (-0.2 = -20%)."""
    out = df.copy()
    factor = out["Asset_Class"].map(lambda cls: max(0.0, 1.0 + shocks.get(cls, 0.0)))
    out["Simulated_Value"] = out["Current_Value"] * factor
    return out


def compare(df: pd.DataFrame) -> dict:
    original = float(df["Current_Value"].sum())
    simulated = float(df["Simulated_Value"].sum())
    delta = simulated - original
    return {
        "original": original,
        "simulated": simulated,
        "delta": delta,
        "delta_pct": delta / original * 100 if original > 0 else 0.0,
    }
```

```python
"""OpenAI integration: portfolio audit and chat. Receives aggregated JSON only."""
import os

import streamlit as st
from openai import OpenAI, OpenAIError

DEFAULT_MODEL = "gpt-4o-mini"
MAX_CHAT_TURNS = 6

AUDIT_SYSTEM_PROMPT = (
    "You are a Certified Financial Analyst (CFA) reviewing an investor's portfolio. "
    "You are given a JSON summary: allocation percentages by asset class, the top 3 "
    "positions, total value and total ROI. Write an executive summary covering risk "
    "exposure, concentration, and diversification, then finish with a bulleted list of "
    "concrete rebalancing action items. Use Markdown. Be concise. This is educational "
    "analysis, not personalised financial advice."
)
CHAT_SYSTEM_PROMPT = (
    "You are a Certified Financial Analyst (CFA) answering questions about the user's "
    "current portfolio. Base answers only on the portfolio JSON below; if the data "
    "cannot answer the question, say so. Use Markdown and keep answers concise. "
    "This is educational analysis, not personalised financial advice.\n\n"
    "Current portfolio (JSON):\n"
)


class AIError(RuntimeError):
    """Any failure of the AI feature, safe to show to the user."""


def is_configured() -> bool:
    return bool(os.getenv("OPENAI_API_KEY"))


def get_model() -> str:
    return os.getenv("OPENAI_MODEL") or DEFAULT_MODEL


def build_audit_messages(summary_json: str) -> list[dict]:
    return [
        {"role": "system", "content": AUDIT_SYSTEM_PROMPT},
        {"role": "user", "content": f"Portfolio summary:\n{summary_json}"},
    ]


def build_chat_messages(
    summary_json: str,
    history: list[dict],
    question: str,
    max_turns: int = MAX_CHAT_TURNS,
) -> list[dict]:
    recent = history[-2 * max_turns:] if max_turns > 0 else []
    return [
        {"role": "system", "content": CHAT_SYSTEM_PROMPT + summary_json},
        *recent,
        {"role": "user", "content": question},
    ]


def _complete(messages: list[dict], model: str, client=None) -> str:
    if client is None:
        if not is_configured():
            raise AIError("OPENAI_API_KEY is not set.")
        client = OpenAI()
    try:
        response = client.chat.completions.create(model=model, messages=messages)
    except OpenAIError as exc:
        raise AIError(f"OpenAI request failed: {exc}") from exc
    text = response.choices[0].message.content
    if not text or not text.strip():
        raise AIError("The model returned an empty response.")
    return text.strip()


def generate_audit(summary_json: str, model: str, client=None) -> str:
    return _complete(build_audit_messages(summary_json), model, client)


def chat_reply(
    summary_json: str, history: list[dict], question: str, model: str, client=None
) -> str:
    return _complete(build_chat_messages(summary_json, history, question), model, client)


@st.cache_data(show_spinner=False)
def audit(summary_json: str, model: str) -> str:
    """Cached by (payload, model); exceptions are never cached."""
    return generate_audit(summary_json, model)
```

```python
        except (pd.errors.EmptyDataError, pd.errors.ParserError, UnicodeDecodeError) as exc:
            st.error(f"Could not read the CSV file: {exc}")
            st.stop()
    if use_sample:
        return pd.read_csv(SAMPLE_PATH)
    st.info(
        "Upload a CSV with columns "
        f"`{'`, `'.join(schema.REQUIRED_COLUMNS)}`, or switch on **Use Sample Dataset** "
        "in the sidebar."
    )
    st.stop()


def apply_filters(holdings: pd.DataFrame) -> pd.DataFrame:
    st.sidebar.header("Filters")
    classes = sorted(holdings["Asset_Class"].unique())
    chosen = st.sidebar.multiselect("Asset Class", classes, default=classes)
    lo = holdings["Purchase_Date"].min().date()
    hi = holdings["Purchase_Date"].max().date()
    picked = st.sidebar.date_input(
        "Acquisition date range", value=(lo, hi), min_value=lo, max_value=hi
    )
    if not isinstance(picked, tuple) or len(picked) != 2:
        st.info("Pick an end date to apply the date range.")
        st.stop()
    start, end = picked
    mask = holdings["Asset_Class"].isin(chosen) & holdings["Purchase_Date"].dt.date.between(
        start, end
    )
    return holdings[mask]

result = schema.validate(load_raw())
for message in result.warnings:
    st.warning(message)
if result.errors:
    for message in result.errors:
        st.error(message)

holdings = result.df
filtered = apply_filters(holdings)

if unavailable:

    for cls in sorted(enriched["Asset_Class"].unique())
}
simulated = scenarios.apply_shocks(enriched, shocks)

tab_dash, tab_stress, tab_ai, tab_export = st.tabs(

# ---------- dashboard ----------

    st.dataframe(

            "Week52_Low", "Week52_High", "Price_Status",
        ]],

            "Purchase_Price": st.column_config.NumberColumn(format="$%.2f"),
            "Purchase_Date": st.column_config.DateColumn(format="YYYY-MM-DD"),
            "Price": st.column_config.NumberColumn(format="$%.2f"),

# ---------- stress test ----------
with tab_stress:
    cmp = scenarios.compare(simulated)
    c1, c2, c3 = st.columns(3)
    c1.metric("Original Value", money(cmp["original"]))
    c2.metric("Simulated Value", money(cmp["simulated"]))

    if not any(shocks.values()):

# ---------- AI ----------
with tab_ai:
    payload = json.dumps(portfolio.ai_summary(enriched), sort_keys=True)

        if saved and saved[0] == payload:

        elif saved:

            try:

            else:
                chat += [
                    {"role": "user", "content": question},
                    {"role": "assistant", "content": reply},
                ]
                with st.chat_message("assistant"):
                    st.markdown(reply)

# ---------- export ----------
with tab_export:
    st.download_button(
        "Download enriched portfolio (CSV)",
        data=export.to_csv_bytes(simulated),
        file_name="portfolio_enriched.csv",
        mime="text/csv",
    )
    if st.toggle("Print-friendly view"):
        st.markdown(f"<style>{export.PRINT_CSS}</style>", unsafe_allow_html=True)
        st.caption("Use your browser's Print / Save as PDF now.")
```
